# UPR 缓存概念验证

本模块是新研究方向的概念验证，不替换GLEEP，不修改历史实验准确率，也不运行源模型前向或下游训练。

## 2026-09-06 实测结论

UPR-v1未通过继续投入门槛，不进入EXP1或新增下游训练。99个任务×4组模型×3个种子全部完成，主种子在共同accuracy上的宏平均结果如下：

| 方法 | Pearson | Kendall | 固定类别数的模型排序 Kendall |
| --- | --- | --- | --- |
| UPR-v1 | -0.310186 | -0.157216 | 0.131256 |
| 确定性GLEEP | 0.906836 | 0.952082 | 0.697395 |
| $1/k$ | 0.836738 | 0.956360 | 未定义 |

速度通过、相关性失败、条件界无效：12个配对端点的预热后中位加速比为77.532倍，但并非每个端点都超过10倍；396个真实模型—任务组合的条件准确率下界全部为0。种子1/2也未达到相关性门槛。反例中常数表征分数几乎最优，共享背景也优于共享语义，说明“容易预测参考结构”不等同于“容易预测真实标签”。

结构诊断发现，$k=100$时异类核相似性约0.597–0.613，真实异类关系为0；$Q$全体均值约0.60，而$A$全体均值为0.01，oracle谱误差约5896–6058。这既暴露了参考关系假设不足，也说明当前统一谱范数界非常保守；不是对所有未来结构风险方法的否定。

首轮主实验141.426秒包含三种子、基线、消融、oracle和报告写入；其中种子0的396项UPR评分累计18.221秒，一次性四模型投影0.174秒。该累计计时不包括其他指标、文件读取或后续GMM计时，不能当作完整端到端复现时间。正式GMM配对计时来自独立复核任务，同一节点、单线程、不含前向。

作业598340（主实验）、598406（预热计时）、598445（完整性复核）均已正常完成，退出码0。19个本地单元测试通过；服务器复核1188条记录、独立复算152组相关性，并在12个缓存端点验证固定种子重复一致。原始结果与计时复核结果的评分和相关性完全相同。

可直接阅读[完整对照表](UPR_RESULTS.md)和[结构与数值复核](UPR_REVIEW.md)。含运行环境绝对路径的原始 JSON 只保留在私有历史归档中，不进入公开仓库。

## 运行

从本目录运行，使用已有兼容的GLEEP环境及四组EXP2缓存：

```bash
python -m unittest discover -s tests -p 'test_upr.py' -v
python -m gleep_repro.upr_experiment --output-dir results/upr-new-run --threads 1
```

输出目录必须不同于已有结果。依赖NumPy、SciPy、scikit-learn、threadpoolctl和现有EXP2任务适配层；不新增训练依赖。固定配置为64维投影、64维RFF、正则化截距、$\alpha=0.01n/65$、主种子0、稳定性种子1/2。默认所有99个任务和4组模型。

评分API输入示意：

```python
from gleep_repro.upr import project_features, score_upr

# 各数组必须对应同一批、同顺序的图像。这里不使用标签或类别数。
projected = {name: project_features(features, seed=0)
             for name, features in aligned_feature_pool.items()}
result, ridge, reference, blocks = score_upr(projected, candidate_name, seed=0)
print(result['score'], result['references'])
```

逐样本归一化和固定投影可在全缓存上复用；带宽和参考RFF按当前任务重建。返回的`reference`是连续关系的低秩分解，不是类别概率。核心中的`structural_diagnostics`是独立、明确需要真实标签的评价函数，不属于部署评分。

## 输出口径

`protocol.json`记录固定参数、代码哈希及环境；`alignment.json`记录官方CIFAR100测试集校验、顺序证据、缓存哈希和缺乏逐图像绑定的限制；`report.json`保存1188条评分记录、所有分组相关性、固定类别数诊断、消融、反例及计时。

主表统一使用各组完整99条`LEEP_ACC.json`；原历史`GLEEP_ACC.json`及64条缺失组另列。`1/k`和`1/n`用于揭示任务规模影响，固定$k$时两者都是常数，相关性未定义。三种随机种子不是三组独立下游实验，不提供虚假的独立样本置信区间。

计时只比较同节点、同线程、已读缓存输入上的评分。投影成本单列，12个预先指定端点测量不能称为完整396项GMM评分计时；复核结果独立保存并排除首次导入和预热。约141秒的首轮主实验包含UPR三种子、基线、消融、oracle及报告写入，不包含随后GMM计时，不是新下游训练用时。

## 决策规则

主种子UPR平均Pearson/Kendall与共同accuracy的确定性GLEEP比较，允许各下降至多0.01；纯评分抽样中位加速要求至少10倍。还须检查简单基线、固定类别数模型排序和条件界是否有效。若相关性失败或条件界全部为0，保留负结果，停止将该原型当作成熟论文改进；不事后翻转分数或选最有利种子。
